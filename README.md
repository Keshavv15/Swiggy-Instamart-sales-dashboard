# 🛒 Swiggy Instamart Sales Dashboard

An interactive Power BI dashboard built to analyze Swiggy Instamart sales performance. This project demonstrates data cleaning, data modeling, DAX calculations, and dashboard design to generate business insights from retail sales data.

## 📊 Dashboard Overview

The dashboard provides insights into:

- 💰 Total Sales
- 📦 Total Orders
- ⭐ Average Rating
- 📈 Average Sales
- 🏪 Sales by Shop City Tier
- 🏬 Sales by Shop Size
- 📅 Sales by Shop Opening Year
- 🛍️ Category-wise Sales Analysis
- 📋 Shop-wise Performance Summary

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## 📈 Key Features

- Interactive slicers for Shop City Tier, Shop Size, and Opening Year
- KPI Cards for business performance
- Dynamic charts and graphs
- Business-friendly dashboard layout
- Clean and responsive visual design
